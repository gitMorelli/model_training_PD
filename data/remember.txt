Scripts
- model_evaluation: runs the evaluation on the selected checkpoint. COmpute predictions for val or for val+train and stores a file
with the predicted values for each unique id+questionnaire in the checkpoint folder for the model 
- create_statistics_on_images: iterate on the images using the data loader. Builds a table with relevant image properties. Merges the information with that 
from other csv table (the original matching csv with covariates, the csv of predictions)
- parallel_create_shards: the num=0 and num=-1 inputs are not saved in the shards (they are empty or missing)

Struttura del json per dataset PD ->
"subject": subject_id, XXXX_YY (id_matchgroup)
"label": label, (0 or 1 , PD label)
"at_least_warning": at_least_warning, (0 or 1, 1 means the control was selected with fallback)
"questionnaire_info": questionnaire_info,
X : Y, 

Ognuna di queste variabili ['etudegp', 'profq2', 'lateralite', 'relative_age', 'birth_date', 'follow_up_time'] è aggiunta 
come X:y mantenendo lo stesso nome
Struttura di questionnaire_info ->
1: 'to_rescale':x, 'rescale_factor':(rescalex,rescaley),'case_dt_dateq': -dt
2:
...
13:
with x=0/1 telling if te image was rescaled
with rescalex and rescaley being the rescaling factors applied (1,1) if no rescaling
case_dt_dateq how many year (float) before the censoring for the case the questionnaire n for the case was filled
